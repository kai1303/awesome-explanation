Building an explainer

Page layout
Lead with the operation, then arrange its stages from left to right. Let the diagram scroll inside its viewport. Put the operation trace below it and the article beneath that.
Type and labels
Use the interface font for headings and explanations. Set keys, file names, bit positions, and sequence numbers in monospace. Show the decision beside the value.
Actions and inspection
Use an Astryx command row for a direct action and a stage disclosure for details. Keep the selected record in view. Inspectors explain the current input, rule, and outcome.
Motion
Animate the record between its measured endpoints with GSAP. Keep the outcome readable after the animation ends. With reduced motion, show the same route and result immediately.
